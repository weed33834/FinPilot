## Wait — is this real?

Yes. And we're a little tired of demos that aren't. Everything you see below came from **actually running the system**:

- The SQL in the query screenshot was generated by a real LLM and executed against a real database.
- The report text was written by a real model — not pasted in by hand.
- The numbers in every chart were **computed by code**, then explained by the model. Never the other way around.

> **Numbers are computed by code. Narratives are written by the model. Every output can be traced back to its source.**

## Why FinPilot?

Three things we actually care about:

1. **The math is real.** Financial computation (DCF, WACC, backtesting, ratios, …) runs on deterministic code. The LLM writes the story, not the spreadsheet.
2. **Everything is traceable.** Every API call, every Q&A turn, every module toggle lands in the run-log. You can replay what the agent did, and why.
3. **Chat is the control panel.** Type `/` in the chat box and a role-filtered command palette appears — admins can drive the whole system from the dialog; regular users only see what they're allowed to.

Plus the usual good stuff, done properly: RAG document Q&A (BM25 + vector + RRF fusion), Excel/PDF/DOCX parsing, ABAC access control, TOTP 2FA, a responsive mobile shell, and a leveled error system that tells you *which* layer broke — not just "something went wrong".

## Quick Start

```bash
git clone https://github.com/weed33834/FinPilot.git   # or any mirror below
cd FinPilot

# backend
python3 -m venv venv && source venv/bin/activate
pip install -e .
cp .env.example .env        # drop in your LLM API key
uvicorn finpilot.api.router:app --host 0.0.0.0 --port 8001

# frontend
cd frontend && npm install && npm run dev
```

Open `http://localhost:5173`, log in with the auto-created admin (`FINPILOT_ADMIN_EMAIL` / `FINPILOT_ADMIN_PASSWORD` in `.env`), and start asking questions.

> LLM providers are managed in **Admin → LLM Providers** (stored in the DB), with env-var fallback. Any OpenAI-compatible endpoint works — Aliyun Bailian, DeepSeek, Zhipu, MoonWeaver, etc.

Docker: `docker compose up -d` (Redis + PostgreSQL + backend + frontend). Details in [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
